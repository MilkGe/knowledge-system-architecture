# 命名规则

文件名是笔记的第一印象，也是知识库可维护性的基础。六条规则覆盖所有文件的命名场景。

## 规则 A：文件名使用连字符代替空格

文件名中不允许出现空格。

| 场景 | ✅ 正确 | ❌ 错误 |
|------|---------|---------|
| 中英混排 | `Hermes-Agent-深度解读.md` | `Hermes Agent 深度解读.md` |
| 纯中文 | `PARA知识管理体系详解.md` | `PARA 知识管理体系详解.md` |
| 纯英文 | `python-decorator-guide.md` | `python decorator guide.md` |

**处理规则**：
- 中英混排：空格 → `-`（连字符）
- 纯中文：空格直接删除（中文不依赖空格分词）
- 纯英文：空格 → `-`（连字符）
- 数字与中文间：空格直接删除（`2026-04-29 报告.md` → `2026-04-29-报告.md`）

## 规则 B：避免中文标点符号

文件名中不允许出现中文标点（全角符号）。

| 原符号 | 替换为 | 示例 |
|--------|--------|------|
| `——`（中文破折号） | `-` 或直接删除 | `深度解读——以学习为核心` → `深度解读-以学习为核心` |
| `（）`（全角括号） | `-` | `聚乙二醇（PEG）` → `聚乙二醇-PEG` |
| `：`（全角冒号） | `-` | `读书与成长（四）` → `读书与成长-四` |
| `、`（中文顿号） | `-` | `Windows更新、Microsoft Store` → `Windows更新-Microsoft-Store` |
| `？`（全角问号） | 直接删除 | `如何做？` → `如何做` |
| `！`（全角叹号） | 直接删除 | `重要通知！` → `重要通知` |
| `“”`（全角引号） | 直接删除 | `"原则"解读` → `原则解读` |
| `；`（全角分号） | `-` | `A；B` → `A-B` |

## 规则 C：URL 来源文件名必须重命名

禁止 URL 转义结果作为文件名。所有来自网络链接导入的文件，必须在入库时赋予有意义的描述性名称。

| ✅ 正确 | ❌ 错误 |
|---------|---------|
| `微信文章-Agent-记忆学习与自进化闭环.md` | `httpsmp.weixin.qq.comswLFWL7Yeqvl_YGusHmYayA.md` |
| `抖音视频-增材制造工艺介绍.md` | `httpsv.douyin.comS8FgO2IfPUE.md` |

**处理方式**：读取内容 → 提取关键词 → 生成有意义文件名（建议格式：`[来源]-[核心主题].md`）。

## 规则 D：日期仅用于时间线笔记

日期前缀 `YYYY-MM-DD-` 仅允许在特定目录中使用。

| 允许日期前缀 | 不允许日期前缀 |
|-------------|---------------|
| `07-Daily/` 及其子目录 | `00-Inbox/`（日期应由 YAML 的 `created` 字段记录） |
| `*/学习日志/` 或 `*/日志/` | `02-Areas/`（按主题组织） |
| `*/进展/` 等迭代式记录目录 | `03-Resources/`（按主题组织） |

## 规则 E：前导下划线仅用于索引文件

前导下划线 `_` 开头的文件名仅限特定索引文件使用。

| ✅ 允许 | ❌ 不允许 |
|---------|----------|
| `_Project索引.md`（排序置顶） | 任何其他文件 |
| `_Area索引.md`（排序置顶） | 测试文件、临时文件等 |

## 规则 F：禁止无意义命名

文件名应反映笔记的核心主题内容。

| ✅ 正确 | ❌ 错误 |
|---------|---------|
| `Python-装饰器-decorator-详解.md` | `test-agent.md`（测试产物） |
| `增材制造-工艺对比维度.md` | `新建文档.md`、`未命名.md`（默认命名） |
| | `不知道.md`（无实质内容） |

**处理方式**：测试文件建议移入回收站；无意义命名读取内容后赋予有意义名称。
